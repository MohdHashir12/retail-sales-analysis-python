# Retail Sales Analysis 📊

This project performs an exploratory data analysis (EDA) on retail sales transaction data to uncover key business insights such as sales trends, product performance, and regional contributions.

## 🧰 Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📌 Project Highlights
- Analyzed sales data from a multi-city retail dataset to identify peak sales periods, top-performing products, and underperforming categories.
- Used Pandas for data cleaning, grouping, and aggregation to prepare insights.
- Created visualizations using Matplotlib and Seaborn to highlight trends in revenue, product lines, and regional performance.
- Delivered actionable findings to support inventory management and marketing strategies.

## 📁 Dataset
The dataset (`Super_International_Market.csv`) contains sales transaction records including:
- Product Line
- City
- Quantity
- Unit Price
- Total Sales
- Rating
- Date & Time of Purchase

## 🚀 Getting Started
To run this project:
1. Clone the repository
2. Open the Jupyter Notebook: `Solution - Super International Market.ipynb`
3. Run the cells in sequence to see data cleaning, analysis, and visualizations

## 📈 Sample Insights
- City A had the highest total sales; Product Line B was the most profitable.
- Evening hours showed peak transaction volume.
- Marketing focus is recommended on high-rating, low-sales products for potential growth.
